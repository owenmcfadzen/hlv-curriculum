# Raw source material

Uncurated input. Claude Code reads from here, never edits.

| Folder | What goes in |
|---|---|
| `decks/` | Old PPTX or PDF presentations (Porto 2025, etc.) |
| `notion/` | Notion page exports (markdown preferred) |
| `worksheets/` | A2 worksheet PDFs (Solution Blueprint, Canvas Lite, etc.) |
| `transcripts/` | Voice notes, meeting transcripts, post-session debriefs |

Files here can be messy. Extraction passes turn them into structured data in `../data/`. See `../prompts/` for task prompts.
