This project's documentation lives in three role-specific files. Read all three before substantive work.

| File | Purpose | Public/Private |
|---|---|---|
| [`AGENTS.md`](AGENTS.md) | Universal Owen-prefs — voice, signals, working style. Apply to any of Owen's projects. | Public |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | The workbench kernel — data model, schema, file layout, validation, the block-driven gap-analysis loop. The system manual. | Public |

If you don't have access to `PROJECT.md`, you're working in the public repo only — you can still operate on the kernel (schema, renderer, validation) but not on project-specific content.

The most recent thinking and conventions are in those three files; this pointer file should stay thin.
